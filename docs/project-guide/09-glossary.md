# 09 — Glossary

| Term                        | Meaning in this project                                                                |
| --------------------------- | -------------------------------------------------------------------------------------- |
| Frontend                    | Pages and interactions visitors use in their browser                                   |
| Backend                     | Server-side services for real data processing; inquiry delivery is not implemented yet |
| Route                       | A page address such as `/my/projects`                                                  |
| Locale                      | A language/formatting choice: `en`, `ja`, or `my`                                      |
| Internationalization / i18n | Structuring code so multiple languages work                                            |
| Localization                | Providing actual translated content and suitable formatting                            |
| Slug                        | URL-friendly identifier, such as `the-terrace`                                         |
| Dynamic route               | One page template that handles different values, such as `[slug]`                      |
| Component                   | A reusable UI building block such as a project card                                    |
| Props                       | Values passed into a component, such as its project record                             |
| Server Component            | Component primarily rendered by the server                                             |
| Client Component            | Component that can use browser state and event handlers                                |
| Hydration                   | Browser JavaScript attaching behavior to server-rendered UI                            |
| State                       | A value that changes during interaction, such as the open gallery index                |
| Query parameter             | A URL value after `?`, such as `category=residential`                                  |
| Hash fragment               | A URL section marker, such as `#residential`                                           |
| Type / interface            | TypeScript’s description of required data shapes                                       |
| Schema                      | Runtime validation rules; Zod checks the inquiry fields                                |
| API                         | An interface through which software exchanges data                                     |
| CMS                         | A content management system; this site currently uses files instead                    |
| Dependency                  | An installed package used by the project                                               |
| Lockfile                    | `pnpm-lock.yaml`, which records resolved dependency versions                           |
| Environment variable        | Configuration supplied outside source code                                             |
| Build                       | Compiled production output generated by `pnpm build`                                   |
| Prerendering                | Preparing page output ahead of a visitor’s request                                     |
| Suspense                    | A React boundary that can show a fallback while content becomes available              |
| Accordion                   | Expandable content panels; here used for services                                      |
| Carousel                    | A collection of slides; here used for sample testimonials                              |
| Lightbox                    | An enlarged image viewer over the page                                                 |
| Reduced motion              | A device/user preference requesting less animation                                     |
| Accessible name             | Text assistive technology and Playwright use to identify a control                     |
| Assertion                   | A test’s statement of expected behavior, such as a visible heading                     |
| E2E test                    | A test that exercises a user flow through a running application                        |
| Headless browser            | A browser running without a visible window                                             |
| Test worker                 | A process running tests; this configuration allows two                                 |
| Trace                       | A recorded test session useful for inspecting failures                                 |
| Fixture/data assumption     | Known sample data a test relies on, such as six projects                               |
| Regression                  | A change that breaks something that previously worked                                  |
| CI                          | Automated checks run by a service after code changes; not configured here              |
| Metadata                    | Page title, description, and sharing information                                       |
| Sitemap                     | A list of page URLs for search engines                                                 |
| robots.txt                  | Crawler instructions; not an access-control mechanism                                  |
| Structured data             | Machine-readable facts about a business; omitted until verified                        |
